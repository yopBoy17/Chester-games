# Chester Games

Небольшая коллекция браузерных игр.

## Игры

| Игра | Описание | Статус |
| --- | --- | --- |
| [Planet Flow](./planet-flow) | Стратегия о захвате планет, потоках энергии и сетевых матчах. | Готова |
| [Factory](./factory) | Фабрика с добычей ресурсов, конвейерами и развитием производства. | В разработке |
| [Угадай карточку](./card-guessing) | Очная игра на двоих с тайными карточками и сетевыми комнатами. | В разработке |

## Planet Flow

Игроки соединяют свои планеты маршрутами, передают энергию, захватывают нейтральные миры и сражаются друг с другом. Есть одиночный режим с ботами, генерация карт, сохранения, PWA и сетевая игра для двух устройств.

```text
planet-flow/
├── index.html             # игра
├── server.js              # сервер для сетевых комнат
├── shared-game-engine.js  # общая логика симуляции
└── package.json           # запуск сервера
```

### Запуск

```bash
cd planet-flow
npm install
npm start
```

После запуска откройте [http://localhost:8080](http://localhost:8080).

---

Новые игры будут появляться в отдельных папках рядом с `planet-flow`.

## Factory
